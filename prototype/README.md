# prototype — Your original designs

Your first designs, kept exactly as you made them. They are the **reference**
for building the real VdoU app in `src/`. Nothing here goes online.

## login/ — Login page design

| File | What it does |
|---|---|
| `index.html` | The page layout: quote on the left, login box on the right |
| `style.css` | All colours, sizes and effects |
| `app.js` | Language switch (5 languages), dark/light mode, card tilt effect, pretend login |
| `galaxy.js` | The moving 3D Andromeda galaxy background |
| `three.min.js` | Three.js library that draws the 3D galaxy |
| `server.js` | Small server to open the page on your computer (not needed in the real app) |
| `logo.png` | Main VdoU logo (used) |
| `logo-dark.png`, `logo-contrast.png` | Other logo versions (not used yet) |
| `galaxy-bg.jpg` | Galaxy picture (not used yet; can be a backup background) |

To view it on your computer: open `login/index.html` in a browser.
