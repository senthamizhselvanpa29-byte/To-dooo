# src/components — Building blocks

Pieces used on many pages. Change one here and it changes everywhere.

| File | What it is |
|---|---|
| `Preferences.js` | Remembers language and dark/light mode |
| `TopBar.js` | Logo, language menu and theme switch at the top |
| `GalaxyBackground.js` | The moving 3D galaxy behind the page |
| `DailyQuote.js` | Today's quote |
| `Icons.js` | Small icons (mail, lock, eye…) |
| `auth/` | Login, sign-up and password forms, and their shared pieces (`FormParts.js`) |
| `app/` | Planner frame: menu (Today, Upcoming, Lists) and account menu |
| `today/` | The Today page: greeting, Plan tomorrow, add task, task list, edit panel |
