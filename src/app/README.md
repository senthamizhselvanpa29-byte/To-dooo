# src/app — Screens and back end

Each folder here becomes a page of the website. Planned:

| Folder | Page |
|---|---|
| `login/`, `signup/` | Log in and sign up |
| `today/` | Today's tasks (main screen) |
| `upcoming/` | Tasks for coming days |
| `calendar/` | Week / month view (Pro) |
| `lists/` | Your lists / projects |
| `settings/` | Language, theme, account |
| `pricing/` | Plans and payment |
| `api/` | Back-end (secret server code): payments, reminders, AI |
