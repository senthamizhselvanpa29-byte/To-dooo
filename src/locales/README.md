# src/locales — Languages

One file per language with every word shown in the app.

| File | Language |
|---|---|
| `en.js` | English |
| `ta.js` | Tamil |
| `ml.js` | Malayalam |
| `te.js` | Telugu |
| `hi.js` | Hindi |

The daily quotes are in `src/data/quotes.js`.

**To add a new language:** follow the steps at the top of `src/lib/i18n.js`.
